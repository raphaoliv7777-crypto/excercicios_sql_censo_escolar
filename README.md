# Mini Projeto de Banco de Dados PostgreSQL (Hospedado no Render)

Este repositório contém a documentação e os scripts SQL de um projeto de banco de dados relacional desenvolvido utilizando **PostgreSQL**, hospedado em nuvem através da plataforma **Render**, e gerenciado localmente com a IDE **DataGrip**.

O objetivo principal deste projeto foi praticar a criação de estruturas relacionais , inserção de dados  e realização de consultas utilizando junções (`JOIN`), filtros (`WHERE`) e restrições de integridade.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

* **Banco de Dados:** PostgreSQL
* **Hospedagem (Cloud):** [Render](https://render.com/)
* **IDE de Gerenciamento:** [JetBrains DataGrip](https://www.jetbrains.com/datagrip/)
* **Linguagem:** SQL (DDL, DML, DQL)

---

## 🛠️ Estrutura do Banco de Dados (DDL)

Durante a criação das tabelas, foram aplicados conceitos fundamentais para garantir a integridade  dos dados:
* Chaves primárias e sequências automáticas (`SERIAL`)
* Restrições de obrigatoriedade (`NOT NULL`)
* Validações de domínio (`CHECK`)
* Relacionamentos entre tabelas (`FOREIGN KEY`)
